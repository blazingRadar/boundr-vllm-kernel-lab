# Quant Review Prompt

Use this when handing a file to your quants:

1. What is this code trying to do?
2. Where is the runtime branch or fallback?
3. What math path is native versus emulated versus fused?
4. What assumptions look too coarse?
5. If you had to suggest one experiment, what would it be?

Do not ask first:
- “can you rewrite this kernel?”

Ask first:
- “what is the decision boundary and is it reasonable?”
